# DataTether

**DataTether** is a project built for the **Meta Global AI Developer Hackathon**.

## Overview
DataTether bridges user data sources with intelligent, privacy-conscious AI agents and workflows.

## Project Structure
```text
DataTether/
├── frontend/      # React + TypeScript user interface
├── backend/       # Python + FastAPI backend server and AI agents
├── sample_data/   # Sample datasets and mock files for local development
├── tests/         # Automated test suites and validation scripts
├── docs/          # Project documentation, guides, and hackathon submission assets
└── README.md      # Project overview and instructions
```
